# python-asteroid-blaster-game-code-sample
code to spawn a laser and move it. built in python using CMU_Graphics which is built on top of pygame.

Asteroid blaster game built in Python.

![Gameplay]<img width="493" height="491" alt="image" src="https://github.com/user-attachments/assets/2036bf77-6faf-4a14-9259-d41a184a0e4f" />

## Features
Multiple game modes [e.g. easy, normal, hard]
[X] Increasing difficulty
Score tracking and leaderboard (leaderboard is manual due to platform limitations)
Main menu, death screen, powerups, settings, and shop
Sound effects
Keyboard controls (work in progress)

## How to run
pip install cmu_graphics
python main.py
